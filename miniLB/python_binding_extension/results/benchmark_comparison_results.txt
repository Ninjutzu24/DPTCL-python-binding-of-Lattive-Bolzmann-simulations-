BENCHMARK COMPARISON: original miniLB vs V5 dpctl + pybind11 + C++ SYCL
==============================================================================

Original miniLB:
  - executable: bgk2dSYCL
  - benchmark file: benchmark_results.csv

V5 implementation:
  - Python allocates USM memory using dpctl.memory.MemoryUSMShared
  - C++ receives USM objects through pybind11
  - SYCL kernels are launched from C++
  - multi-step benchmark loop is executed inside C++

Results:

Lattice        Original MLUPS         V5 MLUPS    Original/V5    V5 % original    V5 OK
------------------------------------------------------------------------------------------
256x256             79.739616        50.729559          1.572           63.62%     True
512x512            221.920848        65.724565          3.377           29.62%     True
1024x1024          204.475520        66.813057          3.060           32.68%     True

Interpretation:
  The original miniLB executable is faster because it is the optimized
  reference implementation. The V5 implementation is a functional
  dpctl + pybind11 + C++ SYCL demonstrator. It is benchmarked on the
  same lattice sizes and number of steps, but it is not yet optimized
  to match the original miniLB performance.
